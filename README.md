# Prompt Studio — 提示词工作台

一个本地运行的 AI 绘图提示词管理工具：存提示词、Grok 自动翻译、逐词中英对应、自由修改、一键生成一组提示词。

## 功能

- **提示词组管理**：左侧多组提示词，随时切换、复制、删除。
- **逐词对应**：每个标签是一个卡片，上面英文、下面中文，双击任意一行直接改。
- **Grok 翻译**：
  - “翻译未译”只翻没中文的标签；“全部重翻”重翻整组。
  - 翻过的词缓存进本地词典，下次同一个词秒出，不再重复调 API。
  - 翻译走术语翻译 system prompt，对绘图标签如实直译。
- **权重**：每个标签 ＋／− 调权重，输出成 `(tag:1.2)` 语法。
- **一键生成**：右上「✨ 一键生成」，输入主题，Grok 产出一组 positive / negative 标签，直接成组。
- **编辑原文**：把整组当逗号分隔文本改，应用后自动重新拆成卡片。
- **存储**：数据存浏览器 localStorage，自动保存；可「导出 / 导入」JSON 备份或搬到别的机器。

## 配置（DSH 方式：填地址 + Key）

不用 `.env`。打开应用后点右上 ⚙️，在设置里填：

- **API 地址**：OpenAI 兼容 base，以 `/v1` 结尾，如 `https://api.x.ai/v1`（中转站地址同理）
- **API Key**：你的 key（官方 `xai-…` 或中转站 key）
- **模型**：如 `grok-4-fast`

点「测试连接」确认通了即可。Key 存在本机浏览器 localStorage，调用时经本地转发
（dev server 的 `/llm/chat`）发往该地址，不跨域、也不打进前端产物。

## 运行

```
pnpm install
pnpm dev
```

然后浏览器打开 http://localhost:5188 ，进设置填好地址/Key/模型。

## 打包

```
pnpm build      # 产物在 dist/
pnpm preview    # 本地预览构建产物
```

> 注意：翻译/生成依赖 dev server 的 `/llm/chat` 转发。`pnpm preview` 和直接打开 dist 里的
> index.html 没有这个转发，翻译/生成会失败。要用翻译功能请用 `pnpm dev`。若要长期用构建
> 产物，需要自己起一个带同样 `/llm/chat` 转发的小服务。

## 模型

默认模型 `grok-4-fast`，在设置里可改成你账号可用的任何 Grok 模型 id。

## 技术栈

Vite 6 + Vue 3 + TypeScript。核心逻辑在 `src/lib/`：

- `tags.ts` 标签解析/权重/序列化
- `grok.ts` Grok 客户端（OpenAI 兼容）+ JSON 提取
- `translate.ts` 批量标签翻译、自然语言翻译、一键生成
- `store.ts` 响应式文档、持久化、词典缓存、导入导出

## 更新（数据不会丢）

数据保存在浏览器里（localStorage + IndexedDB），与程序文件夹分开，按 `http://localhost:5188` 区分。

1. 关闭正在运行的 `启动.bat` 窗口。
2. 解压新版本，覆盖旧文件夹（或解压到新文件夹均可）。
3. 双击 `启动.bat`。

注意：
- 端口 5188 不要改，必须用同一个浏览器打开，否则看不到原来的数据。
- 不要清除浏览器的站点数据。
- 新版本第一次打开时会自动下载一份完整备份（JSON，含返图）；设置里也可以随时点「备份全部数据」。
- 数据丢失时，用「导入」选择备份文件即可恢复。
- 旧格式数据不会被清空：版本不一致时会先保存原始副本再迁移。
